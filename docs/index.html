Frequently Asked Questions

Direct answers to common questions.

Is Hum safe to use?
Yes. Hum is completely open source under Apache 2.0. The code contains zero analytics SDKs, zero ads, and zero telemetry. You can audit every line of source code on GitHub.
Do I need microG, root, or Google Play Services?
No. Hum is a standalone 4.7 MB application. It does not require microG, GmsCore, Magisk, or root access.
Do I need to sign in with an account?
No login is required. You can search, browse, and play any song completely anonymously. If you choose to log in, it uses the official Google web login to sync your personal playlists and likes.
Does Hum host or pirate music?
No. Hum does not host, upload, or distribute any media. It acts as a specialized audio browser that plays streams directly from YouTube Music, stripping ad interruptions and optimizing playback for mobile.
